Spotify's and SoundCloud's own scripts go here. install.sh downloads them from
the services each time it runs (they are not kept in this repository):

  spotify-player.js   Spotify's Web Playback SDK loader
                      https://sdk.scdn.co/spotify-player.js
                      It only opens Spotify's player (sdk.scdn.co) in a hidden
                      frame and talks to it; the player itself always comes
                      fresh from Spotify.

  sc-widget-api.js    SoundCloud's Widget API, for driving SoundCloud's
                      embeddable player
                      https://w.soundcloud.com/player/api.js

They are kept with the installed player (not loaded from the web by the page)
because a browser extension may only run files of its own. To bring them up to
date, run install.sh again.
